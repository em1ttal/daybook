# 0001 · Backend language: Go
*2026-10-23 · accepted*

- **Context:** I need an API for web now and native apps later. I'm also learning backend development.
- **Options:** Node + TypeScript (Fastify), or Go.
- **Choice:** Go.
- **Why:** I learn a second language that is widely used for backends and infrastructure. It compiles to a single static binary, so the Docker image in step 2 is tiny. The standard library alone covers HTTP, JSON, logging and testing. The trade-off is that Go is more verbose than TypeScript and the frontend and backend can't share types; the OpenAPI spec ([0002](0002-spec-first-openapi.md)) solves the type-sharing part.
