# 0007 · Visual identity: Ivory/Fern light, Dim Grey/Lavender dark
*2026-10-23 · accepted*

- **Why:** a calm, natural palette for an app that stays open all day. Measured contrast changed how the colours are used: small Fern text on Ivory fails WCAG AA (3.83:1), so small text and buttons use a darker *Fern Deep*. Lavender on Dim Grey is about 4.1:1, so the dark page uses a deeper grey and Dim Grey becomes the card colour. Details: [style guide](../design/style-guide.md).
